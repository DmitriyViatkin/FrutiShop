# FrutiShop

Адмін-панель для симуляції торгової компанії з продажу фруктів (яблука, банани, ананаси, персики) у реальному часі. Проєкт демонструє роботу з фоновими задачами Celery, чергами задач та WebSockets для live-оновлення даних на фронтенді.

## 🧩 Функціонал

**Автоматична торгівля (Celery Beat + черги):**
- Періодичні задачі закупівлі товару на склад (кожні 6–15 секунд, різна періодичність і об'єм для кожного товару)
- Періодичні задачі продажу товару зі складу за іншими цінами та інтервалами
- Задачі виконуються послідовно в окремій черзі (одна задача за раз)
- Можливість запускати задачі закупівлі/продажу вручну з фронтенду

**Real-time оновлення (WebSockets):**
- Лог операцій (успішні/неуспішні покупки та продажі) виводиться в реальному часі
- Баланс рахунку компанії оновлюється миттєво при зміні
- Toastr-сповіщення про початок/завершення довгих операцій — **тільки для користувача, що їх запустив**
- Захист від повторного запуску вже активної задачі
- Анонімні користувачі не мають доступу до запуску операцій (авторизація обов'язкова)

**Чат:**
- Чат зі збереженням історії повідомлень у БД
- При завантаженні сторінки підвантажуються останні 40 повідомлень
- Бот "Шутник" періодично публікує в чат жарти, отримані через зовнішнє API, з інтервалом, що дорівнює кількості символів попередньої репліки

**Бухгалтерський аудит:**
- Фонова Celery-задача, що виконує тривалу (~15 сек) операцію аудиту з передачею прогресу на фронт через WebSockets

**Завантаження документів:**
- Завантаження декларацій без перезавантаження сторінки (AJAX)

## 🛠 Технологічний стек

- **Backend:** Python, Django
- **Фонові задачі:** Celery, Celery Beat, окремі черги задач
- **Real-time:** Django Channels / WebSockets
- **База даних:** PostgreSQL
- **Frontend:** AJAX, periodic polling, Toastr-сповіщення
- **Інфраструктура:** Docker
- Деплой на сервер через Easypanel
## 🚀 Запуск проєкту

```bash
git clone https://github.com/DmitriyViatkin/FrutiShop.git
cd FrutiShop

docker-compose up --build
```

Сервіси піднімаються в контейнерах: Django-застосунок, PostgreSQL, Redis (брокер для Celery), Celery worker, Celery beat.
